Vista previa — reporte oficial de Power BI Se activa al conectar Azure AD
Normal que aparezca en blanco: Microsoft bloquea su pantalla de login dentro de iframes. En cuanto tengamos AZURE_CLIENT_ID/AZURE_TENANT_ID configurados, este espacio pasa a mostrar el reporte real e interactivo. Mientras tanto: abrir reporte oficial en Power BI ↗
¿Cómo activo el reporte real aquí? →
  1. Entra a portal.azure.com → Microsoft Entra ID → Registros de aplicaciones → Nuevo registro.
  2. Nombre: cualquiera (ej. "Copiloto Power BI"). Tipo de cuenta: "Solo este directorio organizativo".
  3. Plataforma: SPA (Single-page application), URI de redirección: http://localhost:8011.
  4. En Permisos de API → Agregar permiso → Power BI Service → Delegados → Report.Read.All → Guardar.
  5. Si tu organización lo requiere, pide a un admin que dé "Consentimiento del administrador".
  6. Copia el Id. de aplicación (cliente) y el Id. de directorio (inquilino) desde la pantalla "Información general".
  7. Pégalos en .env: AZURE_CLIENT_ID=... y AZURE_TENANT_ID=..., reinicia el servidor.
